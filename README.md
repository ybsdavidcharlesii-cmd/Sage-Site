# Sage Advanced Practice Healthcare — Website

Static single-page site for Sage Advanced Practice Healthcare LLC (sageaph.com).

See `gregorie contextpage.md` for full project context, brand guidelines, and outstanding client items before making changes.

## Stack
Plain HTML/CSS/JS, no framework, no build step. Deployed via Vercel, connected to this GitHub repo — pushes to `main` auto-deploy.

## Local preview
Open `index.html` directly in a browser, or serve it locally:

```
npx serve .
```
